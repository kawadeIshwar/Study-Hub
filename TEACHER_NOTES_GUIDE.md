## 🚀 How to Run

### **Command:**
```bash
cd backend
npm run seed-teacher-notes
```

### **Prerequisites:**
- Teachers must exist (run `npm run seed-teachers` first)
- Database connection configured
- MongoDB running

### **What It Does:**
1. ✅ Fetches all teachers from database
2. ✅ Creates notes based on specialization
3. ✅ Assigns random likes (5-150)
4. ✅ Sets random upload dates (last 90 days)
5. ✅ Generates relevant tags
6. ✅ Saves to database
7. ✅ Shows summary and top notes

## 🔄 Updating Content

### **To Add More Notes:**
Run the script again (won't create duplicates):
```bash
npm run seed-teacher-notes
```

### **To Reset All Notes:**
```javascript
// Delete all existing notes first
await Note.deleteMany({ uploaderRole: 'teacher' });
// Then run seed script
```

### **To Customize:**
Edit `backend/scripts/seedTeacherNotes.js`:
- Modify `noteTemplates` for different subjects
- Change `formats` array for different file types
- Adjust `getRandomNumber(5, 150)` for likes range
- Update `getRandomDate(90)` for date range
