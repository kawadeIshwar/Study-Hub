## 🚀 How to Use

### **Run the Seed Script:**
```bash
cd backend
npm run seed-teachers
```

### **What It Does:**
1. ✅ **Deletes** all existing teachers
2. ✅ **Deletes** all communities created by teachers
3. ✅ **Deletes** all related memberships
4. ✅ **Creates** 20 new Indian teachers
5. ✅ **Creates** 62 new communities
6. ✅ **Sets up** teacher as admin in their communities

### **Login as Teacher:**
1. Go to login page
2. Use any email from the list above
3. Password: `teacher123`
4. Access teacher dashboard
